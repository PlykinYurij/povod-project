# Web

[План разработки с чекбоксами](development-plan.md). [Порядок ревью и совместной работы](../../docs/agent-workflow.md).

Next.js-приложение для будущего публичного сервиса, кабинета, admin и гостевых приглашений. Сейчас E1-01: одна статическая страница, без бизнес-функций. Установка/локальный запуск и проверки — [корневой README](../../README.md), результаты — [отчёт](../../docs/qa/e1-01-report.md).

Маршрутизация — стандартный Next.js App Router в `apps/web/app/`. Каталог `pages/` для другого роутера не создаётся; FSD `_pages` внутри `src/` предназначен для будущих композиций экранов и не является каталогом маршрутов. Пустые FSD-слои заранее не созданы.

Начало работы агенту:

1. Открой проект с рабочей папкой `apps/web` и прочитай [AGENTS.md](AGENTS.md) вместе с [корневыми инструкциями](../../AGENTS.md).
2. Возьми конкретную карточку из [backlog](../../docs/product/backlog.md), проверь [статус подготовки](../../docs/preparation-status.md). Первая реализация — [минимальный каркас](../../docs/product/first-task.md), не весь MVP.
3. Для web-задачи доступен репозиторный skill [povod-web-task](.agents/skills/povod-web-task/SKILL.md). Пример запроса: «Используй $povod-web-task, выполни карточку …; разрешённые файлы …; критерии …». Разрешения и границы всегда задаёт задача.
4. Из apps/web доступны `npm run dev`, `npm run typecheck`, `npm run build`, `npm run start` (последняя после build). Установка `npm ci` из корня; единый корневой lockfile. Typecheck включает Next typegen. Test/lint scripts пока нет.

Skill расположен в `apps/web/.agents/skills`, чтобы обнаруживаться при старте из web. По официальной документации Codex ищет репозиторные skills вверх от cwd; если стартуешь из корня и skill не появился, используй явный путь выше. Перезапусти/обнови список skills способом своего клиента, если новая файловая запись не появилась в уже открытой сессии. Автообнаружение именно в этом клиенте ещё не проверено; ссылка на SKILL.md остаётся доступной.

Внешние skills/плагины и пользовательские настройки не устанавливались. Для текущих задач достаточно локальных инструкций; Figma/GitHub-доступы нужны только соответствующим отдельным работам. Источники: [AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md), [skills](https://learn.chatgpt.com/docs/build-skills), проверены 11 ноября 2026.
