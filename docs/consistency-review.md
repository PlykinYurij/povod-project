# Сверка подготовки после QA и операций

10 ноября 2026. Промпт 3 завершён до составления backlog: независимые предложения QA/DevOps получены без правок; ведущий подготовил планы. Затем выполнен Промпт 4: сверка, исправление однозначных расхождений и локальные карточки. Самопроверка итогового текста не называется независимым QA приложения.

Приоритет: решения владельца (последние D-19–22) → рабочее ТЗ с исходными FR/NFR → производные документы. Исходное ТЗ сохранено без изменений, история D сохранена с явным правилом приоритета поздних решений.

## Исправленные однозначные расхождения

| Область | Было в ранних производных материалах | Действующее правило / основание |
| --- | --- | --- |
| Менеджер | Прежний pnpm по D-22 | Только npm workspaces по D-23; npm 11.20.0 доступен |
| Health первой задачи | `/api/v1/health` | Root GET `/health`; бизнес API остаётся `/api/v1` |
| RSVP | v1 без формы, rsvp:null / будущая v2 | D-16: фиксированная форма в первой публикации; технический PR RSVP может быть позже каркаса, но до выпуска продукта |
| Изменения после публикации | Полный read-only или полноценное изменение draft | D-17: draft заблокирован, отдельные текстовые коррекции по whitelist; структура/анкета/фото/даты неизменны |
| Неизменность снимка | Изменение draft после публикации как обычный путь | Тест прямого PATCH обязан получить отказ; успешная текстовая коррекция создаёт новый immutable-снимок, сбой сохраняет старый |
| Срок | 90 дней — предложение | D-19: бесплатно выдано 90 дней расхода, без фиктивной оплаты |

| Места | Пауза освобождает / освобождение истечением открыто | D-11/18: пауза удерживает, полное истечение освобождает, проверка атомарна |
| Хранение | Старые анкеты хранятся бессрочно либо 30 дней | D-20/21: effective soft-delete контента/фото/ответов при истечении; физическая очистка отдельно Q-19 |
| Администрирование | Только admin разрешает возобновление | D-08: владелец может сам resume, два режима расхода срока сохраняются |
| Лимиты | 5 draft / 10 фото / 15 МБ / 40 Мп ещё предложения | Приняты D-15; учёт версий/единицы уточнить в Q-08 |
| Экспорт | Только CSV как безусловный MVP | XLSX принят; CSV остаётся Q-17, исходный FR-18 сохранён со ссылкой на уточнение |
| Готовность | Макеты/план воспринимаются как проверенное приложение | QA-кейсы Planned, карточка каркаса Blocked, прошлые HTML-проверки — исторические свидетельства только эскиза |

В архитектуре/API и UX-матрице исправлены rsvp:null/v2 и трактовка места, read-only и срока. Прежний implementation-plan заменён навигацией к backlog/первой карточке, чтобы не поддерживать две конкурирующие очередности. Существующие ID §13 сохранены; разделение широких работ описано в backlog.

## Что не сделано

Нет приложений/миграций/зависимостей/workflow/серверов. Не подтверждены npm, установка по lockfile, HTTP `/health`, typecheck/build или dev/prod. Не запускались проверки продукта. Системные настройки и внешние сервисы не менялись, коммит/push не выполнялись.

Результаты статической проверки документов и неизменности исходника приведены в [preparation-status](preparation-status.md). После ревью следующая работа — устранение B-02, затем отдельная E1-01; на готовой карточке текущая задача заканчивается.
