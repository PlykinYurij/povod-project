# Журнал разработки

Для каждой карточки сохраняй ссылку на проверенный коммит, результаты проверок исполнителя, вывод независимого ревью, результаты QA и ограничения. Для блокирующего дефекта укажи участок, решение и коммит повторного ревью. Если проверки выполнялись на разных коммитах, укажи SHA для каждой. Результат интеграционных проверок привязывай к SHA из `mvp` и записывай после их выполнения. Статус карточки веди в [backlog](product/backlog-v2.md).
