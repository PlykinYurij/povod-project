## Текущие принятые правила

Частные пользователи РФ, четыре шаблона, форма/предпросмотр без перестановки, одна общая ссылка, email/пароль без дополнительного подтверждения после входа. Два бесплатных места, включая паузы, по 90 дней расхода. Фото/черновики: пять draft, 10 фото/15 МБ/40 Мп. RSVP входит в первую публикацию; максимум 300 хранимых ответов события. После публикации только текстовые исправления, без смены структуры/анкеты/фото/даты/шаблона. XLSX; CSV ещё Q-17.

Пауза останавливает остаток и занимает место; admin может снять без паузы расхода, владелец сам возобновляет. Полное истечение освобождает место и эффективно soft-delete пользовательское приглашение, фото и ответы независимо от worker/cron. Окончательная очистка/восстановление Q-19, бэкапы Q-10. Дата события не запускает бизнес-действия. Игры, открытки и платежи отложены. Поздние решения заменяют старое бессрочное хранение и R-01 без анкеты.

Менеджер первой задачи теперь **npm workspaces** по поручению, root **GET /health**; business API позже `/api/v1`. Каркас без БД/auth/RSVP/media/deploy. Это не противоречит обязательному RSVP в первом пользовательском продукте: технический каркас не является продуктовым релизом.
