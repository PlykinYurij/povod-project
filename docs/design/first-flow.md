# UX первого сценария

Статус: низкодетальный проект для ревью. [Открыть автономный HTML](first-flow.html) в браузере; он не обращается к сети, не загружает файлы и не сохраняет данные. Ссылки верхней тёмной панели и переключатели состояний — инструменты ревью, не интерфейс продукта. Значения синтетические. Подробно показан один шаблон из четырёх, без выдачи остальных за готовые.

## Поток и экраны

| Экран / hash | Поля и действия | Результат |
| --- | --- | --- |
| Выбор `#templates` | «Тихий сад», краткое демо, выбор. Второй свадебный и два праздничных — только обозначение будущего объёма | Вход email/пароль, если нет сессии, затем создание. В HTML сессия условно есть; регистрация не спроектирована этим артефактом |
| Редактор `#editor` | Название только владельцу; имена, дата/время/пояс, место; опциональные маршрут/фото/программа, готовая палитра | Сохранение ревизии, приватный предпросмотр. Нет drag-and-drop, смены шаблона и произвольных стилей |
| Предпросмотр `#preview` | Тот же контент в мобильной/настольной ширине; пометка «Только вам», переход назад или к публикации | Ничего не опубликовано, срок не начинается; RSVP не работает в preview |
| Подтверждение `#confirm` | Сводка, бесплатный тариф, условный пример периода; публичность ссылки и окончательная фиксация контента; явное подтверждение проверки | Запрос publish с expectedRevision и одним ключом. Сервер определяет окончательное время начала; реальные сроки только из offers |
| Успех `#published` | URL, копирование с обработкой отказа, открытие гостевой, чтение данных проекта | Есть только отдельное действие исправления текстов, без редактирования структуры. В HTML успех — имитация, ссылка на example не действующая |
| Гостевая `#guest` | Только опубликованные имена/дата/место, включённые блоки. Нет title, email владельца и кабинета | Чтение без аккаунта. Недоступность — отдельный нейтральный экран без данных |
| RSVP в v1 `#rsvp` | Имя, участие, сопровождающие; тот же эскиз формы показан на гостевой | Форма фиксируется с первой публикацией, после неё не меняется |

## Поля и оформление

Общая схема с API и данными — [traceability.md](traceability.md). «Место» конкретизировано названием и адресом как предложение A-01. Время/дата только отображаются, прошедшие значения допустимы, дополнительных предупреждений нет (D-13). Фиксированный текст приглашения принадлежит TemplateVersion, не тайному полю редактора.

Кабинет: системный sans-serif, белые карточки, нейтральная подложка, тёмно-зелёный акцент, единые поля/кнопки/статусы. В эскизе все секции открыты; мобильная форма в одну колонку, предпросмотр отдельным экраном. Ширина 360 px и переключатель «Мобильная ширина» дают просмотр editor/guest на телефоне. Длинные сообщения не перекрываются нижней панелью.

Шаблон «Тихий сад»: молочная бумага, крупные serif-имена, тонкая геометрия, свободные поля и две готовые палитры. Это собственное направление, не копия Vowee; содержимого страниц или скриншотов референса нет. CSS-декор и плейсхолдер фото не требуют лицензирования чужой фотографии. Полноценный подбор шрифтов/изображений отложен. Низкая детализация сохраняется: приоритет — иерархия, поля и состояния, а не финальная графика.

## Состояния и ошибки

Переключатель в редакторе показывает пустой черновик, загрузку, сохранение, сетевую ошибку, конфликт, обработку/ошибку фото и квоту. Это альтернативные макеты, не симулятор серверной логики.

- **Пусто:** нейтральные заглушки, обязательные поля отмечены. Предпросмотр текущего сохранённого контента возможен с ошибками готовности, publish требует полной схемы.
- **Сохраняется / ошибка:** нет преждевременного «сохранено»; ввод остаётся видимым. При истечении сессии нужен повторный вход и сверка фактической ревизии. Молчаливое перезаписывание конфликта запрещено.
- **Фото:** передача, обработка и ready различны. При ошибке повторить либо явно выключить блок; публикация не выбрасывает выбранное фото молча. Точные лимиты ещё Q-08.
- **Квота:** два места заняты, включая паузы. Не предлагать паузу как освобождение места. Момент освобождения при истечении пока Q-01.
- **Публикуется / потерян ответ:** кнопка блокируется на время запроса; статус «Проверяем результат» и повтор той же операции. «Не опубликовано» допустимо лишь после подтверждённого отказа, а не любого таймаута.
- **После успеха:** структура и анкета фиксированы; разрешены только текстовые исправления через отдельное действие (D-17).
- **Гостевая недоступна:** нейтральный экран без имён/адреса/формы и внутренних причин admin. Сбой сервиса отличается от установленной недоступности, не показывать ошибку БД как истечение срока.

## Следующая вертикаль: анкета

Эскиз показывает небольшую форму и подтверждение после отправки. При отказе сопровождающих ноль (D-04), лимит сопровождающих и дополнительные вопросы Q-04 не выбраны; опции 0/1/2 в HTML — демонстрационные. Нужно согласовать состав формы данного шаблона. Можно начать с имени и участия, а затем отдельным согласованием выбрать сопровождающих/трансфер; произвольного конструктора нет.

В реальном API успех только после принятия; потеря ответа сети требует повтора с тем же ключом без дубликата. Все 300 хранимых записей считаются по проекту, одинаковые имена разрешены, событие и пауза не удаляют ответы; полное истечение запускает мягкое удаление D-20. Любая недоступность сайта запрещает **новый** ответ. Чтение ответов и XLSX владельца — последующая функция. Юридические основания/согласия перед реальными анкетами — Q-10, HTML не делает вид, что документы уже готовы.

R-01 о новой версии без изменения старых проектов отклонено D-16: форма входит уже в v1.

## Figma и пределы проверки

Точный Figma-файл и подтверждённый доступ на запись не предоставлены; подходящего доступного инструмента записи не обнаружено. Перенос не выполнялся. Если позже будет доступ, отдельная задача сначала проверяет чтение целевого файла и создание редактируемых frames/text/components, затем переносит сетку, поля/состояния и mobile-версии. Импорт PNG не считается редактируемым макетом.

Локальный HTML достаточен для ревью. Он демонстрирует концепцию, не доказывает работу API, доступность всего продукта, поддержку браузеров или выполнение NFR скорости.

## Изменения после ревью D-14–18

RSVP входит в первую гостевую. Перед публикацией: «После публикации можно исправлять только тексты. Фото, даты, шаблон, блоки и анкета останутся неизменными». После успеха доступно отдельное исправление текстов; черновой редактор блокирует остальные поля. Шаблон и место приняты. Лимиты фото/черновиков и период 90 дней приняты D-15/19. Прежнее описание R-01 и read-only ниже/выше заменено этим решением; серверный контракт коррекций описан отдельно.

## Действующая политика истечения D-19–21

Период принят: каждый бесплатный проект получает 90 дней расхода. В подтверждении публикации показано предупреждение об удалении пользовательского приглашения, фото и ответов после полного истечения. На паузе остаток и данные сохраняются. После истечения место свободно, гостевая недоступна; обычное чтение/коррекция/XLSX удалённых данных не обещаются. Задержка до окончательной очистки и восстановление пока Q-19. Ранее описанное сохранение анкет после истечения отменено D-20.
