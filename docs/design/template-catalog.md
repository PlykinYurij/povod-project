# Каталог шаблонов · E2-01b, read-only

Реализация поверх принятых identity и [«Тихого сада»](quiet-garden.md). Это отдельная review-часть, не новый полный MVP и не утверждение создания проектов. [Карточка](../product/e2-01b-catalog.md).

Путь: главная → «Посмотреть шаблоны» → `/templates` → «Посмотреть демо» → существующее приглашение. В демо ссылка «К шаблонам» возвращает в каталог. Кабинет доступен из навигации, но эта стадия не создаёт черновик и не запоминает выбор. Неактивных/фиктивных кнопок создания нет.

Карточка получает локализованные метаданные от API, показывает оригинальную code-owned иллюстрацию сада, название, палитры и явную ссылку на демо. Четыре шаблона запланированы для MVP, готовая карточка пока одна. Остальные не представлены как работающие варианты. Изображение декоративное, доступное название ссылки содержит имя шаблона; клавиатура не проходит дважды по одному и тому же demo-link.

Системный sans-serif, serif-заголовок, молочная подложка, зелёный акцент и spacing-токены сервиса. На 360 px карточка и навигация не выходят за экран. Public catalog остаётся серверным и не подключает providers кабинета; RU/EN меняет интерфейс/метаданные каталога, не содержимое приглашения владельца.

Состояния: отдельное «Загружаем шаблоны…» при ожидании; нейтральный empty; явный error с retry при сети/503/повреждённом payload; готовый список. Страница ошибки не содержит диагностических данных API и не предлагает действие над несуществующим проектом.

Работающий UI: `http://127.0.0.1:3000/templates` после запуска web/API. Проверенные снимки [1280 px](template-catalog-review/desktop-ready.png) и [360 px](template-catalog-review/mobile-ready.png) сняты с production-сборки и просмотрены исполнителем, не выданы за независимое дизайн-ревью. Low-fi [first-flow.html](first-flow.html) сохранён, Figma не менялась. [QA](../qa/e2-01b-catalog-report.md) различает реальные HTTP-проверки и фикстуры ошибок.
