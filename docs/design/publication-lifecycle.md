# Снятие публикации и возврат к редактору · E4-01b

[Открыть макет](publication-lifecycle.html) · [Действующие сценарии работы с заявкой](assisted-flow.md) · [Архитектура](../architecture/assisted-publication.md) · [D-43 и допущения](../product/implementation-assumptions.md)

В макете переключатели над экраном задают роль, состояние и ответ сервера. В приложении состояние приходит из API. Сценарий начинается в приватном разделе проектов и сохраняет связь с заявкой. На desktop поля помещаются в одну строку, на mobile карточка переносит поля и действие на несколько строк.

| Состояние | Экран и действие |
| --- | --- |
| Опубликовано | Администратор открывает диалог «Снять с публикации». Объясняем, что текущая ссылка и новый RSVP станут недоступны, сохранённые ответы останутся, редактор откроется. |
| Подтверждение | Два варианта без выбора по умолчанию. «Приостановить срок» — PAUSE_PERIOD. «Продолжить отсчёт» — KEEP_RUNNING. Причина обязательна, 1–240 символов после обрезки краёв. Ошибка под полем. Подсказка просит не указывать персональные данные. |
| Запрос отправлен | Сообщение «Снимаем с публикации…». Повторная отправка, изменение полей и закрытие диалога недоступны до ответа. |
| Ответ потерян | «Не удалось подтвердить результат». Повтор отправляет ту же операцию с исходными режимом, причиной, версиями и ключом. |
| Конфликт | «Проект изменился». Обновить данные и повторно сверить статус. Другой администратор мог снять приглашение, поэтому действие не повторяется автоматически. |
| Нет доступа | Сообщение об отказе без деталей проекта. Повторное снятие в диалоге недоступно. Приватные данные на рабочем экране следуют действующим правилам сессии и прав. |
| Снято | Состояние берётся из серверного lifecycle, а выданная ранее квитанция остаётся историей. Показываем выбранный серверный режим. Владелец может менять содержимое и фото через существующий редактор. Шаблон проекта сохраняется. |
| Гость | По старой ссылке нейтральное «Приглашение недоступно». RSVP, данные владельца и причина снятия скрыты. |
| Срок истёк | Редактор этого проекта недоступен. Истечение и мягкое удаление не отменяются через снятие. |

Повторное размещение выполняет только администратор после проверки актуального предпросмотра. Макет уточняет снятие. Сценарий возобновления не показывает новый срок, цену или автоматически создаваемый заказ. Открытые условия остаются в [Q-29](../product/open-questions.md).

## Сверка при реализации

- Передать в запросе ожидаемую редакцию проекта и версию публикации. При повторе после сетевого сбоя сохранить исходный набор полей и тот же ключ.
- Отличать текущий серверный статус от сохранённой квитанции и обновить список и детали после успешного действия.
- Проверить ширины 360 и 1440 px, клавиатурную навигацию и возврат фокуса из диалога, отсутствие выбора по умолчанию, ожидание, конфликт, отказ и повтор. Для длинной причины проверить сообщение поля и переносы на mobile.
