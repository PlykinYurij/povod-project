# Инструкции агенту макетов

- Действуют вместе с [корневым AGENTS](../../AGENTS.md). Начни с [плана](development-plan.md), [существующих артефактов](README.md) и [порядка ревью](../agent-workflow.md).
- Выполняй только назначенный пакет, сохраняй существующие макеты и пользовательские изменения. Правки — в `docs/design/**`; продуктовые правила/API/код приложения не менять без отдельного поручения.
- Согласованные решения владельца важнее эскизов. Открытые Q явно помечать, не утверждать предположения через макет. Поля, лимиты, ошибки и состояния сверять с API и FR/NFR.
- Кабинет/admin — согласованный Mantine и light/dark; приглашения — оригинальные шаблоны. Показывай mobile, ожидание, пустые/ошибочные состояния, focus и длинные тексты.
- Просматриваемые макеты — автономный HTML без сетевых зависимостей и реальных персональных данных. Figma/внешние сервисы не менять без поручения. Демонстрация не доказывает работу приложения.
- Фиксируй фактически просмотренные экраны/размеры/состояния. Не выдавай отсутствие ошибок HTML за визуальную проверку. После пакета отметь только выполненный результат и остановись на ревью; принятие/main — по явному сообщению владельца и проверке.
- Итог: изменено; проверено; не проверено и почему; вопросы. Commit/push — только по поручению.
