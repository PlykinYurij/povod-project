# E2-03c · Фото в редакторе и приватном предпросмотре

FR-10/11, NFR-08/09/10. [ТЗ](../povod-mvp-spec-v0.1.md) · [Приём оригиналов](e2-03-photo-intake.md) · [Обработка](e2-03b-photo-worker.md).

- Личный и операторский редакторы показывают список загрузок и статусы. При сбое повтор с тем же выбранным файлом сохраняет ключ. На время обработки фото видно в списке, а доступно для выбора только после READY.
- Выбор меняет поле `content.heroMediaId`. Для изменения сохранённой обложки нужно сохранить черновик. Действие «Без фото» снимает выбор и сохраняет загруженный файл в списке. Удаление оригинала отдельно.
- API сохраняет heroMediaId только для готового фото того же проекта. Незавершённое, отсутствующее и чужое фото получают одинаковую ошибку поля. Проверка работает для обоих редакторов.
- `GET …/photos/{photoId}/image` возвращает только WebP готовой попытки с `private, no-store` и `nosniff`. Гость не получает файл. Владелец читает свой проект. Администратор читает фото из связанных с заявками проектов, а загружает и редактирует только операторский черновик. URL и ключ S3 не раскрываются.
- Приватный предпросмотр использует сохранённое фото. В браузере Blob URL освобождается при уходе со страницы. Для гостевой публикации выдача и отзыв доступа определяются отдельно. Q-09 остаётся открытым.

Для локальной приёмки нужны API, web и worker из [инструкции хранилища](../operations/photo-storage.md). В редакторе выберите файл, загрузите, дождитесь «Готово», выберите обложку и сохраните. Откройте приватный предпросмотр и проверьте изображение. Затем смените выбор на «Без фото» и проверьте, что сохранённая обложка исчезла, а файл остался в списке. Повторите в редакторе оператора из общей заявки.

Прошли 175 общих и 233 API/БД-проверки. Проверки HTTP подтверждают 404 для незавершённого и чужого фото, отказ сохранить чужой ID, защитные заголовки и совпадение байтов с готовым WebP. В Chrome с PostgreSQL, worker и локальным S3-стендом пройдены загрузка, ожидание, выбор, сохранение и просмотр в обоих редакторах. Запрос без сессии получил 401. Мобильный приватный предпросмотр проверен на 360 px. Для этого этапа нет миграции.
