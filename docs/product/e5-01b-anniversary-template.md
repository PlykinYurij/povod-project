# E5-01b · «Письмо о юбилее»

Основание: FR-01, FR-06, FR-07, R2-01/02/11, D-36/37/40. [Backlog](backlog-v2.md) · [Макет и поля](../design/anniversary.md) · [Хранение версий](../architecture/template-schema-evolution.md)

Каталог использует ID `anniversary`, категорию `birthday`, версию `birthday-anniversary-v1` и ключ рендерера `anniversary-v1`. Демо доступно по `/templates/anniversary`. Редактор, API и рендерер используют имена и пределы полей из макета. Начальная локаль `ru`. В черновике допускаются пустые обязательные поля. При публикации проверяются имя, дата, время, часовой пояс, место, адрес и подпись кнопки RSVP. Фото допускает пустой выбор, а заданный UUID должен принадлежать проекту и ссылаться на готовое медиа.

Создание, сохранение, предпросмотр, заявки, публикация и RSVP используют существующие маршруты и правила доступа. Гостевой API отдаёт ссылку на обложку по снимку. Уже сохранённые проекты используют свой прежний валидатор и рендерер. Цена остаётся в Q-27. Для сквозной проверки допустима синтетическая цена только в изолированной БД. Каталог включается отдельной миграцией после проверки реализации.

## Приёмка

- Владелец выбирает шаблон в каталоге, правит письмо, дату, место и подпись, загружает и выбирает готовое фото. Предпросмотр показывает сохранённую версию на языке приглашения.
- Из предпросмотра владелец отправляет заявку. Администратор публикует тот же проект. По гостевой ссылке открывается правильный рендерер с публичной обложкой, а ответ RSVP сохраняется за этим снимком.
- API отклоняет правку другого владельца и несовместимую схему. Необязательные секции корректно скрываются. В демо и предпросмотре RSVP отключён. Ошибка загрузки фото оставляет письмо и форму гостя доступными.
- Демо и гостевая страница работают при 360 и 1280 px, с reduced motion и длинным содержимым. Смешанный каталог сохраняет доступ к трём текущим версиям.
- Проверки включают сборку, типы, воспроизводимость OpenAPI/Orval, целевые тесты с PostgreSQL и браузерный прогон. Независимые ревью и QA привязываются к SHA кандидата.
