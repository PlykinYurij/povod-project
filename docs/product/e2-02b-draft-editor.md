# E2-02b · Редактор черновика «Тихий сад»

Требования FR-06–08 из [исходного ТЗ](../povod-mvp-spec-v0.1.md) и D-36/37/43 из [решений](decisions.md). Форма работает с [проверенным API черновиков](e2-02-private-drafts.md) и [версией схемы](e2-01-content-schema.md).

1. В «Моих проектах» действие «Редактировать» доступно, когда сервер возвращает `canEditDraft`. Прямой URL с UUID сохраняется через вход. Сервер выдаёт одинаковый 404 для чужого и отсутствующего проекта.
2. React Hook Form заполняет редактор значениями сохранённой версии. Можно менять название, палитру, язык служебных подписей, имена, дату и время, место, до 12 пунктов программы и все 14 текстов. Уже сохранённый язык сохраняется, пока пользователь его не изменит. Переключение языка не меняет его тексты. Пустые тексты отправляются как есть. Выключенная программа отправляется как `null`.
3. Сохранение отправляет полный черновик и `expectedRevision`. Кнопка блокируется на время запроса. После успеха форма получает сохранённые значения и новую ревизию. Сервер проверяет длины, формат и права. Ошибки по путям полей отображаются рядом с полями.
4. Сетевой сбой или 401 сохраняет ввод на открытой странице. При 401 можно войти в новой вкладке. При 409 редактор блокирует повторную запись устаревшей ревизии. Кнопка «Заменить мои правки версией с сервера» явно сбрасывает локальные поля после успешного GET. Автоматического слияния нет.
5. Предпросмотр — E2-02c. Загрузка фото — E2-03. Редактор сохраняет полученный `heroMediaId` в данных и не предлагает загрузку. Публикация остаётся операцией администратора следующих этапов.

## Локальная приёмка

Запустите `npm run dev:api:database` и `npm run dev:web` из корня. Создайте проект «Тихий сад», откройте его на `/account` и измените вступление или время. Сохраните и перезагрузите страницу. Для проверки конфликта откройте один и тот же черновик в двух вкладках до правок, сохраните разные названия последовательно. Во второй вкладке проверьте сохранность локального ввода и загрузите актуальную редакцию по кнопке.

## Проверки

- Vitest — 168 проверок. Новые проверки покрывают пустой текст, `program: null`, следующую ревизию, сохранность ввода при 409 и обработку 422 у поля.
- В Chrome с NestJS и PostgreSQL редактор открылся из списка владельца и сохранил имя в ревизию 2. Второй PATCH сохранил ревизию 3. Запись из редактора получила 409 и оставила локальное название. Пользователь загрузил серверную версию, сохранил заново и получил ревизию 4. Перезагрузка показала сохранённое название.
- Просмотрены 360 px в светлой теме на русском и 1280 px в тёмной теме на английском. Формы 401 и locked не прогонялись в браузере на этом этапе.
- Проверки типов, формат, сборка web и API успешны локально. Проверки GitHub относятся к соответствующему PR.
