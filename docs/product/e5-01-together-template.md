# E5-01 · Шаблон «Вдвоём»

Шаблон `wedding-together-v1` дополняет «Тихий сад» в категории свадьбы. [Макет и поля](../design/second-wedding.md) · [Версии схемы](../architecture/template-schema-evolution.md) · [FR-01/06/07](../povod-mvp-spec-v0.1.md) · [R2-01/02/11](acceptance-criteria.md)

## Контракт подключения

- Версия шаблона выбирается при создании и читается из проекта при сохранении. Один реестр выбирает строго типизированную схему, начальное содержимое, проверку готовности и расположение ссылки на фото по версии. Неизвестная версия возвращает ошибку. Для Garden остаются прежние JSON, маршруты, ограничения и рендерер.
- OpenAPI перечисляет оба типа содержимого. Контракт записи проверяет поле `content` по неизменяемой версии существующего проекта, указанной на сервере. На чтении версия и содержимое позволяют интерфейсу выбрать конкретную форму и гостевой рендерер без предположения, что все проекты относятся к Garden.
- Публичная выдача передаёт только текущий снимок и безопасный идентификатор обложки. Для «Вдвоём» ссылка на фото хранится в `photo.mediaId`, публичный ответ замещает её идентификатором снимка по действующему правилу Garden. Подготовка изображения и лимиты остаются общими.
- Набор полей RSVP для «Вдвоём» совпадает с уже проверенным набором имени, участия и сопровождающих. Разные версии шаблонов могут применять одну совместимую схему анкеты. Тексты шаблона редактируются, служебные сообщения формы переводятся на языке приложения.
- Каталог показывает новую версию только после готовности формы, демо, предпросмотра, публикации и гостевой страницы. Неутверждённые реальные цены Q-27 отсутствуют в каталожных данных, QA использует синтетические цены.

## Проверка поставки

Для обычного владельца и сопровождаемого заказа подтвердить создание, редактирование, выбор готового фото, приватный предпросмотр и публикацию администратором. Для гостя подтвердить правильный рендерер, доступ к обложке и RSVP без выдачи внутренних идентификаторов. На первом и втором шаблонах проверить совместимость старых черновиков и снимков, отклонение полей чужой схемы, приватность и сохранение версии.

Команды — `npm run typecheck`, `npm run build`, `npm run test:web`, интеграционный `npm run test:database`. После экспорта OpenAPI и генерации Orval проверить воспроизводимость артефактов. В браузере проверить мобильную и широкую версию, длинные значения, отключённую анимацию, состояния фото и пустые необязательные разделы.
