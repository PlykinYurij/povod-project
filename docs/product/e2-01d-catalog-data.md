# E2-01d · Категории, версии и цена шаблона

21.11.2026, реализовано/проверено, Review; feat/template-catalog-data. База main 3626e47 + проверенная зависимость ab2e9bd (E2-02d), ещё не owner acceptance/main. FR-01/05/06, R2-01/02/08/12, D-39/40.

Результат PR: аддитивные TemplateCategory/Template/TemplateVersion и FK существующих projects.templateVersionId; публичный каталог читает DB, сохраняет code-owned renderer/defaults/пути и не рекламирует несуществующие формы. Обязательная регистрация только для создания проекта, не для каталога. Самостоятельная публикация не добавляется.

## Согласованный для реализации контракт

- GET /api/v1/templates: optional locale ru/en и category (slug до 64 символов). Неизвестные/повторные/неверные параметры 422; неизвестная корректная категория даёт пустые items, не 404. categories содержит активные категории; items — только доступные зарегистрированные версии.
- Summary сохраняет прежние поля и добавляет templateId, categoryId, price. price — `{ amountMinor, currency: "RUB", version }` либо null, если прайс ещё не настроен. Деньги — целое число копеек, не float.
- Нулевую выдуманную цену не ставим: seed Garden содержит price=null. Это **техническое отсутствие прайса**, не обещание бесплатности. UI показывает «Цена уточняется»; реальный прайс Q-27 требуется к публичному приёму заказов/публикации. Рабочая валюта RUB — допущение ведущего, не ответ владельца о сумме.
- Категории свадьба/день рождения/гендер-пати не означают три готовых renderer: пока доступен один Garden. Другие категории допустимы пустыми.
- POST /projects принимает прежний контракт; перед созданием проверяет активность категории/шаблона/версии внутри транзакции. Недоступная/неизвестная версия — 404 TEMPLATE_NOT_FOUND. Повтор прежнего create key всё равно возвращает исходный проект даже после скрытия шаблона.
- Скрытие не удаляет старые проекты, не меняет их JSONB/schema/revision и не запрещает владельцу сохранять поддерживаемый draft. Version/schema/defaults/renderer должны соответствовать реестру кода; произвольная DB строка не становится исполняемым шаблоном.
- Цена фиксируется версиями для будущих заявок; момент согласования Q-27 пока отдельно, никакого платежа. Новых admin price-edit routes/публичного изменения цены в этом PR нет.

Критерии: типы/OpenAPI → Orval, миграция без потери старых проектов, категории/фильтр/пусто/неизвестные поля, null/настроенная цена, отсутствие credentials в public fetch, недоступный template/create replay, FK/unique/check, безопасные display/link поля, понятная 503 при отсутствии БД. Изменение live snapshot/медиа/RSVP/публикация не входят.

Проверки: test PostgreSQL/HTTP, Vitest frontend transport/display fixtures, typecheck/build, format, воспроизводимая генерация. Результаты записываются после выполнения, заранее успешными не считаются.
