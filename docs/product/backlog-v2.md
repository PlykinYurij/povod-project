**21.11.2026, D-42–44:** заявки не блокируют draft; published полностью read-only, unpublish возвращает редактор. Admin готовит общий заказ. Работа продолжается последовательно с [явными допущениями](implementation-assumptions.md), не выдавая review/main за выполненные. Порядок ближайших задач: E2-02d → E2-01d → V2-02/V2-01 → редактор/preview/admin UI → медиа/RSVP/publish. Общие зависимости сохраняются.

20.11.2026, изменение D-38/39. Это актуальный план следующих реализаций. [Прежний backlog](backlog.md) сохраняет историю выполненных ID, не поручает реализовывать старый self-publish. Одна карточка — один принимаемый PR; разработка, принятие владельцем и main отмечаются отдельно.

Готовая база: E1-01/02/05/06/07, identity E1-04/04b/04c/04d, E2-01a/схема, read-only часть E2-01b и E2-02. В main 3574643 вошли E2-02d, E2-01d и API заявок V2-02/V2-01. UI выбора и создания черновика E2-01b и редактор E2-02b подготовлены к ревью. Следующий этап — E2-02c. [Карточка E2-01b](e2-01b-draft-creation.md) · [Карточка E2-02b](e2-02b-draft-editor.md).

Обозначения: R2-01–12 — новые **требования** из acceptance-criteria; V2-00–06 — новые **карточки задач**. Существующие E-ID сохраняются. Не смешивать requirement ID и task ID.

Уточнение UX клиентского/операторского пути и роли/admin permissions использует выбранный JSONB D-40; не требует переноса данных в subtype-таблицы. Нельзя параллельно менять общий API/lockfile/ownership mapper без одного ответственного; отдельные checkout и владельцы файлов по agent-workflow. В этой задаче субагенты не запускались, независимое ревью не заявлено.

Ни одна новая реализационная карточка не отмечена Ready автоматически. V2-00 готов к обсуждению; для конкретного следующего PR ведущий проверит его Q/документы/инструменты и выделит одну область. GitHub Projects не менялся; ID/role/dependencies/FR-NFR-Q/verification/owner accepted/main SHA можно использовать как поля карточек, статусы Backlog → Ready → In progress → Review → Done, Blocked с точной причиной.

E2-04c (текстовые правки при published) отменена D-43, ID не переиспользовать. Пока опубликовано, редактирования нет; после снятия полный редактор без смены шаблона. Исторические ожидания старых карточек не реализовывать.
