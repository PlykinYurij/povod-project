# V2-03 · Очередь заявок и предпросмотр администратора

Сценарий чтения покрывает FR-24, R2-05/09/10 и администраторскую часть E2-02c. [Исходное ТЗ](../povod-mvp-spec-v0.1.md) · [Критерии](acceptance-criteria.md) · [UX](../design/assisted-flow.md).

- `/admin/projects` требует сессию и роль ADMIN. Оба серверных метода проверяют роль на каждом запросе. Гость получает 401, обычный пользователь — 403. Открытие ссылки на кабинет администратора не расширяет доступ к owner URL.
- `GET /api/v1/admin/requests` читает до 30 заявок. Очередь упорядочена по времени подачи и UUID в убывающем порядке. Следующая страница использует `after` из ответа. В таблице есть тип, шаблон, название проекта, имя пользователя и статус. Отсутствие аккаунта и отсутствие имени показаны отдельно.
- `GET /api/v1/admin/requests/{id}` возвращает детали одной заявки с контактами, отправленной ревизией, сохранённой ценой и текущим связанным черновиком, если он доступен. Контакт выводится как текст. Предпросмотр использует тот же рендерер и не принимает ответы гостей.
- Оба ответа имеют `Cache-Control: no-store`. В очереди отсутствуют контакты и JSON черновика. Начало обработки и отказ описаны в [статусах V2-03](v2-03-request-status.md). Создание проекта из общей заявки и публикация остаются следующими частями.

Запустите `npm run dev:api:database` и `npm run dev:web`. Войдите под локальной учётной записью с ролью ADMIN и откройте `/admin/projects`. Откройте связанную заявку, сравните отправленную и текущую версии, проверьте предпросмотр. В общей заявке проекта нет. [Выдача локальной роли](../operations/admin-access.md).

## Проверки

- 225 API/БД-проверок. Новые сценарии подтверждают разграничение 401/403, отзыв роли, разделение списка и контактов, валидацию курсора и отсутствие дублей при одинаковом времени подачи.
- 171 общая проверка, типы, сборки и форматирование. OpenAPI 0.14.0 и Orval воспроизводятся. Миграций для этих двух GET нет.
- В Chrome обычный пользователь получил отказ. Синтетическая учётная запись с ролью ADMIN увидела две заявки. После открытия деталей появились контакт и текущая ревизия 5 при отправленной ревизии 4. Просмотрены 360 и 1280 px. На 360 px таблица прокручивается внутри панели.
