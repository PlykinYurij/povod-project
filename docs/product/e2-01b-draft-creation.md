# E2-01b · Выбор шаблона и создание черновика

Требования FR-01/05/25 из [исходного ТЗ](../povod-mvp-spec-v0.1.md) и R2-01 из [MVP v2](mvp-v2.md). Доступны [контракт каталога](e2-01d-catalog-data.md), [API черновиков](e2-02-private-drafts.md) и [пользовательский путь](../design/assisted-flow.md).

- Категория передаётся в GET каталога. Фильтры остаются доступны при пустом результате. Каталог показывает цену из API либо «Цена уточняется».
- Выбор карточки открывает `/projects/new?templateVersionId=…`. Для доступной версии гость проходит вход с сохранением адреса. Создание требует явного подтверждения.
- Поля POST — название длиной до 24 Unicode code points после trim и проверенная версия шаблона. Ошибки названия видны под полем. API отвечает за квоту, наличие версии и принадлежность проекта.
- При неопределённом исходе форма сохраняет отправленное название и UUID в течение жизни открытой формы. Повтор отправляет тот же запрос. Если пользователь покинул или перезагрузил страницу, проверить результат можно в кабинете.
- Успешное сохранение открывает кабинет. Список запрашивается у API и различает загрузку, пустой результат и ошибку. Редактирование входит в E2-02b.

Для локальной приёмки запустите `npm run dev:api:database` и `npm run dev:web` из корня. На `http://127.0.0.1:3000/templates` выберите «Тихий сад», войдите, введите название и проверьте черновик в «Моих проектах». В категории «День рождения» при текущем наборе шаблонов ожидается пустой результат.

## Проверки

- `npm test` — 164 проверки. Новые проверки покрывают назначение фильтров и ссылки, сохранение выбранной версии после входа, Unicode в названии, отказ из-за квоты и повтор с неизменным ключом.
- `npm run typecheck`, `npm run build`, `npm run format:web` — успешно.
- Chrome с локальными Next.js, NestJS и PostgreSQL — фильтр «День рождения» пуст, «Свадьба» содержит «Тихий сад», фокус достигает выбора. Гость проходит вход, возвращается к выбранной версии, сохраняет черновик и видит его в кабинете. В test-БД у синтетического владельца появилась одна запись с нужной версией. Проверены 360 и 1280 px, светлая и тёмная темы, RU/EN.
- Квота и потеря ответа проверены тестами компонентов с управляемым ответом API. Hosted CI учитывается после push.
