# E2-02c и V2-05 · Предпросмотр владельца и отправка заявок

FR-09/11 и R2-02/03/04/08/09/10. [Исходное ТЗ](../povod-mvp-spec-v0.1.md) · [Критерии](acceptance-criteria.md) · [Контракты V2-01](v2-01-project-publication-request.md) и [V2-02](v2-02-public-service-request.md).

- Кабинет открывает `/projects/{id}/preview`. Серверный HTML содержит оболочку. После проверки сессии браузер читает сохранённые данные через owner GET с `no-store`. API проверяет владельца, а чужой и отсутствующий проект получают один 404. Администратор открывает предпросмотр через [детали заявки V2-03](v2-03-admin-request-queue.md).
- Видны номер сохранённой ревизии, подсказка о заполненности и оригинальный рендерер «Тихого сада». В редакторе предпросмотр открывается в новой вкладке, поэтому текущий ввод остаётся в редакторе. Блок анкеты в предпросмотре содержит пояснение. Приём RSVP и загрузка фото входят в отдельные этапы.
- Из предпросмотра можно отправить заявку на публикацию. Запрос передаёт показанную ревизию и версию цены. Если цена или версия поменялись, можно обновить данные и затем явно повторить отправку. Пустая цена отображается как «цена уточняется».
- После отправки показываются номер заявки и ожидаемое действие администратора. После перезагрузки виден статус открытой заявки, её ревизия и согласованная на момент отправки цена, если она настроена. Более новая ревизия в проекте помечается отдельно. Правки остаются доступны. После закрытия последней заявки владелец видит итоговый статус и может отправить новую. [Переходы](v2-03-request-status.md).
- С главной можно перейти на `/request-help` и оставить имя для обращения, телефон, канал Telegram/MAX/VK, контакт и согласие на связь. Для этой формы сессия не требуется. Она не создаёт проект или аккаунт. Контакт отображается оператору как текст.
- После неопределённого ответа открытая форма сохраняет исходный ключ и полное тело запроса для безопасного повтора. На новой странице или после перезагрузки ключ хранению не подлежит. Для заявки с проектом открытый статус доступен при следующем входе. Юридический текст и правила хранения остаются в Q-10, реальные цены — Q-27.

## Приёмка

Запустить `npm run dev:api:database` и `npm run dev:web` из корня. Войти, открыть сохранённый черновик в «Моих проектах» и нажать «Предпросмотр». Проверить ревизию и отправить заявку на синтетических контактах. Перезагрузить страницу и проверить статус. Изменить черновик и проверить, что отправленная ревизия осталась прежней. В окне без сессии открыть `/request-help` и отправить общую заявку.

- Vitest — 170 проверок, включая отказ без согласия и повтор с тем же телом и ключом после обновления данных.
- Chrome + Next.js + NestJS + test PostgreSQL — приватная ревизия, редактирование после заявки, отображение открытого статуса после перезагрузки, отсутствие данных проекта в анонимном HTML, вход с возвратом по приватной ссылке и общая заявка без сессии. В БД проверены две записи с ожидаемыми привязками. Проверенный мобильный предпросмотр — 360 px, тёмная тема, английский кабинет и русское приглашение.
- Реальное истечение сессии во время отправки, платёж и публичная публикация в этом браузерном прогоне не проверялись.
