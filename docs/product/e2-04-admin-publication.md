# E2-04 · Первая публикация администратором

Опубликовать можно подготовленный проект из заявки владельца или общей заявки. Администратор заново открывает актуальный предпросмотр, проверяет зафиксированную стоимость и задаёт поддомен. Открытая заявка позволяет редактировать проект до публикации. Если черновик меняется, сервер требует свежую ревизию. [D-38–43](decisions.md) · [FR-11/12/24](../povod-mvp-spec-v0.1.md) · [R2-07/08/09/10](acceptance-criteria.md).

## Запрос и ответы

`POST /api/v1/admin/requests/{id}/publish` требует сессию с актуальной ролью ADMIN, разрешённый Origin, CSRF и UUID в `Idempotency-Key`.

| Поле | Значение |
| --- | --- |
| `expectedRequestVersion` | Версия открытой заявки из карточки администратора |
| `expectedProjectRevision` | Ревизия проекта, которую администратор только что просмотрел |
| `expectedPriceVersion` | Версия зафиксированной цены из заявки. Смена каталожной цены не заменяет её |
| `slug` | 3–63 символа из строчных ASCII-букв, цифр и дефисов, без дефиса по краям |

201 возвращает `{publicationId, snapshotId, url, requestVersion, publishedAt, expiresAt}`. Это квитанция о совершённой операции. Тот же UUID и те же данные по этой заявке возвращают её с 200. Повтор не расходует срок, не открывает истёкшее приглашение и не меняет текущий статус. При неопределённом сетевом исходе интерфейс должен повторить исходный запрос с тем же UUID.

| Ответ | Причина и действие |
| --- | --- |
| 401/403 | Нужен вход администратора и действительная защита CSRF |
| 404 | Заявка или её действующий проект недоступны |
| 409 `REQUEST_PROJECT_REQUIRED`, `REQUEST_STATE_CONFLICT`, `REVISION_CONFLICT` | Сначала подготовить проект или обновить заявку и предпросмотр |
| 409 `PRICE_NOT_CONFIGURED`, `PRICE_CHANGED` | Нет согласованной цены или просмотрена другая версия. Запрос не назначает цену |
| 409 `SLUG_TAKEN` | Адрес занят. Сохранить ввод и предложить другое имя |
| 409 `PUBLICATION_LIMIT_REACHED` | Два места аккаунта заняты. Операторские проекты без аккаунта не расходуют места администратора |
| 409 `ALREADY_PUBLISHED`, `IDEMPOTENCY_KEY_REUSED` | Заявка уже завершена другим запросом или данные изменены для ранее принятого ключа |
| 422 | Некорректный ввод, зарезервированный slug, незаполненный контент или выбранное фото не готово либо принадлежит другому проекту |
| 503 | Ошибка сервиса или отсутствует корректный базовый домен |

## Атомарность и границы

- Записи пользователей блокируются в порядке UUID. Далее для проекта с владельцем порядок такой же, как у приёма заявки и сохранения черновика. Для операторского проекта сначала блокируется заявка, затем проект. Запись RSVP делит блокировку проекта с публикацией.
- Один commit резервирует адрес, сохраняет независимый JSONB-снимок с `garden_v1`, выставляет первый срок и блокирует редактор, закрывает заявку и записывает квитанцию с ID администратора. Срок составляет 90 суток от времени БД. Дата события на срок не влияет. Снимок уже доступен API RSVP после commit.
- Уникальный индекс решает гонку за slug. При гонке за второе место запись пользователя сериализует запросы. Скрытая публикация с действующим сроком занимает место, истёкшая освобождает его по времени. Политика паузы и повторного размещения добавится в E4-01.
- Миграция `20261122000000_publication_receipt` добавляет таблицу квитанций. [Операторский интерфейс и гостевой HTML](e2-04b-guest-page.md) подключены в следующем коммите. Для внешнего адреса остаются реальные цены Q-27, DNS и TLS.

## Локальная проверка

При запущенной локальной PostgreSQL выполните из корня `npm run db:migrate:test`, `npm run build --workspace @povod/api`, затем `npm run test:database`. Сценарии используют отдельную test-БД, синтетическую цену и домен `invitations.example.test`. Проверяются права, ревизия, цена, фото, загрузка анкеты и ответ после publish, повторы, гонки за адрес и слот и откат транзакции при поздней ошибке PostgreSQL.

Для новых публикаций API читает `PUBLIC_INVITATION_BASE_DOMAIN`, например `invitations.example.test` локально. Это имя без протокола, порта или пути. `PUBLIC_INVITATION_RESERVED_SLUGS` дополняет встроенный список `app,admin,www,api,mail,support` через запятую. Для воспроизведения набора test вручную менять dev-прайс или DNS не требуется. OpenAPI 0.20.0 и generated Orval содержат контракт для следующей карточки.
