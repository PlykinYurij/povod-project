Статус backend **принят владельцем**, результат проверен в main `9c0cc4c`. Источники FR-02/NFR-07/09/14/15, D-28/29. [QA исходного backend](../qa/e1-04-report.md). Web-форма ещё не реализована; Session/автовход/CSRF расширяют контракт в [E1-04b](e1-04b.md). Родительский ID не закрыт целиком без frontend.

Результат PR: users migration/unique normalized email, Argon2id, DTO/unknown-field validation, POST /api/v1/auth/register, безопасный response/errors, Origin/CORS, настраиваемый throttle, Swagger UI/OpenAPI JSON и tracked snapshot для будущего Orval. Локальные команды — [инструкция](../operations/registration.md).

Приёмка:

1. Только email/password, пароль 8–128 печатных ASCII-символов, только латинские буквы, минимум A–Z/0–9/спецсимвол; без trim/обрезки. Email trim/lowercase, точки/plus сохраняются.
2. 201 отдаёт только user.id/email; в БД salted Argon2id, роль/ownerId/другие серверные поля отклоняются 422. Hash/пароль не отражаются в response/errors.
3. Последовательный/конкурентный normalized duplicate — 409 EMAIL_UNAVAILABLE, одна строка. SQL уникальность — последняя защита от гонки.
4. Мalformed JSON 400, body limit 413, неверный Content-Type 415, неверные DTO 422, Origin 403, limiter 429/Retry-After, зависимость недоступна 503. No-store для мутации и ошибок.
5. HTTP-тесты на отдельной test-БД проверяют границы, hash/salt/verification, гонку, CORS/Origin, ошибки, forwarded-IP spoof и limiter. Cleanup только точных синтетических email теста.
6. Live/exported OpenAPI описывает поля, response/errors/operationId; CI после сборки регенерирует snapshot и проверяет diff. Orval и UI — следующий потребитель принятого контракта, не часть этого PR.
7. Чистая установка/типизация/сборка, все suites и kit проходят на Windows/Linux; runtime smoke проверяет native Argon2 hash/verify из изолированного архива с --ignore-scripts.

D-29 принял register 5/IP/15 минут и Session/автовход. Актуальный контракт требует CSRF bootstrap и устанавливает session-cookie; прежний stateless register принят как базовый E1-04, затем расширен E1-04b. [Текущий запуск/ограничения](../operations/sessions.md). Reset/письма и web отдельно.
