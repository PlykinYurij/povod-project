# E2-03b · Обработка фотографий

FR-10/11 и NFR-10. [Исходное ТЗ](../povod-mvp-spec-v0.1.md) · [Приём оригиналов](e2-03-photo-intake.md) · [Локальный запуск](../operations/photo-storage.md).

- Отдельный worker забирает задачи `PROCESSING` из PostgreSQL с `FOR UPDATE SKIP LOCKED`. Он обрабатывает одну фотографию за раз. Аренда длится две минуты. Если процесс исчезнет, другой сможет взять задачу после её окончания.
- Перед декодированием проверяются размер, формат и SHA-256 оригинала. Sharp исправляет ориентацию EXIF и сохраняет WebP без исходных метаданных. Получаются версии до 1600 и 480 пикселей по длинной стороне без увеличения оригинала. [Ориентация Sharp](https://sharp.pixelplumbing.com/api-operation/#autoorient) · [Выходные метаданные Sharp](https://sharp.pixelplumbing.com/api-output/).
- Версии записываются в приватное хранилище под ключами попытки. `READY` появляется только после подтверждения обеих записей и действующей аренды. PostgreSQL хранит токен готовой попытки и размеры версии 1600. Оригинал не становится доступным из API.
- Сбой хранилища оставляет задачу для повтора через 15 секунд после первой попытки или 60 после второй. На третьем сбое, при истекшей третьей аренде или при ошибочном оригинале запись становится `FAILED`. Готовая запись повторно не берётся.
- Частичные версии не доступны пользователю. Они остаются в приватном бакете до отдельной очистки вместе с оригиналом и записью проекта. Выбор и выдача готовой версии в редакторе следуют в E2-03c.

Проверка доступна через `npm run test:database` после сборки и миграции тестовой БД. Для локального запуска worker нужны отдельный терминал и настройки [хранилища](../operations/photo-storage.md).

Прошли 174 общие и 233 API/БД-проверки, типы и обе сборки. Тест с PostgreSQL и локальным S3-стендом подтвердил одну выдачу при двух конкурентных запросах, восстановление после истёкшей аренды, сохранение `PROCESSING` при отказе второй записи и финальный WebP с исправленной ориентацией без EXIF. Проверены повреждённый оригинал и истёкшая последняя попытка. Команда запуска без конфигурации завершилась с ожидаемым кодом 1. Внешний бакет и работа процесса в окружении размещения ещё не проверены.
