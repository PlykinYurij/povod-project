# Каталог с PostgreSQL · Локальный запуск

[Архитектура](../architecture/catalog-data.md), [карточка](../product/e2-01d-catalog-data.md), [QA](../qa/e2-01d-catalog-data-report.md). После E2-01d каталог требует dev DB; прежний read-only каталог без DB — история.

Из корня PowerShell, Docker/PostgreSQL по существующему [локальному плану](local-development.md):

```powershell
npm run db:migrate:dev
npm run dev:api:database
# В другом терминале
npm run dev:web
```

Откройте /templates в web. В API доступны GET /api/v1/templates?locale=ru и ?locale=en&category=wedding, без аккаунта. category=birthday или неизвестный корректный slug дают пустой items, не ошибку сервиса; категории могут существовать до готового дизайна. Ошибочный locale/category/повтор/неизвестные параметры дают 422. Без DB каталог даёт 503, а /health остаётся 200; используйте dev:api:database, не считайте это отсутствием шаблонов.

Seed содержит один реализованный Garden, три категории и **ненастроенную цену null**. UI показывает локализованное «Цена уточняется». Синтетические суммы в тестах не являются прайсом и не попадают в dev seed. Реальные RUB суммы/правила фиксации Q-27 потребуются к публичному приёму заказов/публикации; платежи не реализуются этим этапом. Новых команд изменения цены нет, не используйте выдуманный npm script. Безопасное управление каталогом — отдельная операторская задача.

Для проверки изоляции/availability/FK/ограничений: сначала API build, затем npm run db:migrate:test и npm run test:database. Миграция аддитивна и при неправильной старой templateVersionId откажет FK-проверкой; не удаляйте проект и не делайте reset ради обхода ошибки, исследуйте несовместимую запись отдельно. Production миграции/DNS/релиз не выполнялись.
