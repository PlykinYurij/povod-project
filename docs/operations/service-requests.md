# Общая заявка · Локальная работа

V2-02: [контракт](../product/v2-02-public-service-request.md), [QA](../qa/v2-02-service-requests-report.md). Web-форма и operator queue пока отдельные задачи; готов только API/SDK. Отправка не публикует сайт и не отправляет сообщения людям.

В корне PowerShell:

```powershell
npm run db:migrate:dev
npm run dev:api:database
```

POST http://127.0.0.1:3001/api/v1/service-requests: JSON по карточке, Origin http://127.0.0.1:3000, Idempotency-Key UUID, без cookie/CSRF. Это реально проверено HTTP-тестами на временных loopback API, а не обещание готовой формы. Возвращает только requestId/status RECEIVED/createdAt, 201 либо 200 при повторе. Не используйте этот UUID как ссылку на приватную заявку.

Применена двенадцатая аддитивная миграция service_requests/service_request_rate_limits. Проекты/аккаунты/публикации при общем обращении не создаются; cookies существующей сессии не привязывают заявку. Предоставленные документы/материалы получает оператор при общении, здесь uploads нет.

10 новых заявок/IP/15 минут и 3/телефон/час — рабочая политика A-07. При 429 учитывайте Retry-After; потерянный ответ повторяйте с тем же key/body, не создавайте новый ключ автоматически. HMAC ключи rate не содержат raw IP/phone; expired counters чистятся порциями до 500 каждые 60 секунд. Это очистка технических счётчиков, **не удаление контактных данных**.

SERVICE_REQUEST_RATE_SECRET — минимум 32 случайных байта в hex (чётная длина), одинаковый для экземпляров dev/staging/production. Local без него использует эфемерный process fallback; при перезапуске/смене fallback гарантии rate между процессами не сохраняются. В production без корректного секрета новые заявки получают 503, существующие auth/liveness не выключаются. Ни значение, ни DB URL не логируются. Генерация/выдача production секретов, SMTP/мессенджер API и публичный запуск здесь не выполнялись.

До публичного доступа отдельно проверить реальную proxy/IP цепочку, edge anti-bot/rate ограничения всех HTTP запросов (валидация тела сама не ограничивает весь трафик), юридический текст и цели/сроки контактных данных Q-10, delivery/backup/privacy runbook. Сейчас request.ip использует socket peer, поддельный X-Forwarded-For не доверяется; за неизвестным proxy нельзя объявлять корректную квоту клиентов. Контактные записи не наследуют 90 дней публикации и не стираются автоматически таймером rate. Владелец не передавал production доступов, выпуск не заявлен.
