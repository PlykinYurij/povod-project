# Контракт этапа E1-01

Технический этап по [карточке](../product/first-task.md), не первый продуктовый релиз. Ведущий зафиксировал эти границы до параллельной работы web/API; дизайнер отдельно уточняет существующий макет будущего сценария.

| Часть | Результат | Ожидание / ошибка |
| --- | --- | --- |
| Web `GET /`, порт 3000 | Статическая RU-страница с h1 «Повод» и честным сообщением, что создание приглашений пока недоступно | Нет запросов данных и формы, поэтому data-loading/submit-success отсутствуют; недоступный сервер — ошибка соединения. Занятый порт не считать успешным стартом |
| API `GET /health`, порт 3001 | HTTP 200, application/json, ровно `{"status":"ok"}` | Только liveness процесса. Не обещает БД, почту или готовность бизнеса; не зависит от них |
| API запуск | По умолчанию bind `127.0.0.1:3001`, можно задать PORT | PORT только целое 1..65535; неверное значение/занятый порт дают ненулевой выход. SIGINT/SIGTERM закрывают приложение |
| Поля | Нет пользовательского ввода/персональных данных | Никаких вымышленных DTO, публикаций или ответов гостей |

Web пока не вызывает `/health`; эта проверка выполняется отдельно по HTTP, поэтому здесь не нужны CORS, proxy, Query и Orval. Business API позже `/api/v1`; root `/health` остаётся исключением. Swagger/валидация бизнес-DTO входят в будущие API-карточки. TypeScript strict уже в обоих workspace; runtime-проверка PORT не подменяет будущую валидацию HTTP.

Разделение файлов: frontend — `apps/web/app`, tsconfig/next-env; backend — `apps/api/src`, tsconfig/Nest config; дизайнер — три существующих файла first-flow/traceability в `docs/design`. Ведущий единолично ведёт manifests, lockfile, команды, контракт и сводку. Общий checkout используется этой координируемой сессией с непересекающимися файлами; субагенты не выполняют Git-операций. Независимые сессии с собственными ветками требуют разных worktree.

Будущий макет сохраняет путь «Тихий сад → редактор → preview → подтверждение со slug → гостевая + RSVP». Его loading/error/success и неподтверждённые Q-03/04/16 описываются в [UX](../design/first-flow.md); наличие макета не добавляет эти функции в каркас.
